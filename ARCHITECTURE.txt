║                          AUTH FLOW SEQUENCE                                ║
╚════════════════════════════════════════════════════════════════════════════╝

SIGNUP FLOW:
──────────────────────────────────────────────────────────────────────────────

  1. User visits /auth/signup
  2. User fills form (name, email, password, confirm)
  3. User clicks "Sign Up"
  4. React: authClient.signUp.email({ email, password, name })
  5. Browser: POST /api/auth/sign-up/email
  6. Next.js: Route handler → auth.toNextJsHandler()
  7. Better Auth:
     ├─ Hash password
     ├─ Create user in MongoDB (users collection)
     ├─ Auto-signup = auto account creation
     └─ Create session token
  8. Response: { user, session, token }
  9. Browser: Set HTTP-only cookie (better-auth.session_token)
  10. React: Redirect to /secondStage
  11. Browser: GET /secondStage
  12. Middleware: Check cookie → Found → Allow
  13. Page: Load with user info


LOGIN FLOW:
──────────────────────────────────────────────────────────────────────────────

  1. User visits /auth/login
  2. User fills form (email, password)
  3. User clicks "Log In"
  4. React: authClient.signIn.email({ email, password })
  5. Browser: POST /api/auth/sign-in/email
  6. Next.js: Route handler → auth.toNextJsHandler()
  7. Better Auth:
     ├─ Find user in MongoDB (users collection)
     ├─ Compare password hash
     ├─ Validate credentials
     └─ Create session token
  8. Response: { user, session, token }
  9. Browser: Set HTTP-only cookie (better-auth.session_token)
  10. React: Redirect to /secondStage
  11. Browser: GET /secondStage
  12. Middleware: Check cookie → Found → Allow
  13. Page: Load with user info


GOOGLE OAUTH FLOW:
──────────────────────────────────────────────────────────────────────────────

  1. User visits /auth/login or /auth/signup
  2. User clicks "Log in with Google" / "Sign up with Google"
  3. React: authClient.signIn.social({ provider: 'google', callbackURL: '...' })
  4. Browser: Redirect to Google OAuth screen
  5. Google: User logs in / authorizes app
  6. Google: Redirect to /api/auth/callback/google?code=...
  7. Next.js: Route handler receives auth code
  8. Better Auth:
     ├─ Exchange code for access token (Google API)
     ├─ Fetch user data from Google
     ├─ Find or create user in MongoDB (users collection)
     ├─ Create account link (accounts collection)
     └─ Create session token
  9. Response: { user, session, token }
  10. Browser: Set HTTP-only cookie (better-auth.session_token)
  11. Browser: Redirect to /secondStage (callbackURL)
  12. Middleware: Check cookie → Found → Allow
  13. Page: Load with user info


PROTECTED ROUTE ACCESS:
──────────────────────────────────────────────────────────────────────────────

  Not Logged In:
  1. User visits /secondStage
  2. Browser: GET /secondStage
  3. Middleware: Check for better-auth.session_token cookie
  4. Middleware: Cookie NOT found
  5. Middleware: Redirect to /auth/login?redirectTo=/secondStage
  6. Browser: Navigates to /auth/login with redirect param
  7. Page: Shows login form

  After Login:
  8. User logs in (see LOGIN FLOW above)
  9. Session token set in cookie
  10. Redirect to /secondStage
  11. Browser: GET /secondStage
  12. Middleware: Check for better-auth.session_token cookie
  13. Middleware: Cookie FOUND
  14. Middleware: Allow request
  15. Page: Loads AI learning UI


LOGOUT FLOW:
──────────────────────────────────────────────────────────────────────────────

  1. User clicks "Sign Out" button (in top-right of /secondStage)
  2. React: signOut() or authClient.signOut()
  3. Browser: POST /api/auth/sign-out
  4. Next.js: Route handler
  5. Better Auth:
     ├─ Invalidate session token
     ├─ Remove from sessions collection (MongoDB)
     └─ Clear cookie
  6. Response: Success
  7. Browser: Clear HTTP-only cookie
  8. React: Redirect to /auth/login
  9. Next request to /secondStage gets redirected (no cookie)
